# Faye / Fmaverick

**I build AI-native products for work, writing, and self-direction.**  
**我在构建面向工作、写作与自我驱动的 AI 原生产品。**

Most software is either technically impressive or actually useful.  
I care about the second category.  

大多数软件要么“技术上很厉害”，要么“真的有人会天天用”。  
我更在意后者。

I’m especially interested in products that turn messy human workflows into something clearer, faster, and more repeatable.  
我尤其关注那些能把混乱的人类工作流，变得更清晰、更高效、更可复用的产品。

我正在持续构建一组小而锋利、带明确观点的软件产品，方向包括：

## Selected Work / 代表项目

### [cover-generator](https://github.com/Fmaverick/cover-generator)
An AI-assisted cover creation tool for Xiaohongshu-style content workflows.  
一个服务于小红书内容工作流的 AI 辅助封面生成工具。

This project is less about image generation itself and more about operationalizing creative taste into a fast, repeatable publishing system.  
这个项目真正有意思的地方，不是“生成图片”，而是把内容审美变成高效、可复用的发布系统。

### [boss-agent-cli](https://github.com/Fmaverick/boss-agent-cli)
An agent-first CLI for BOSS 直聘 workflows, from search and filtering to recruiter operations and resume optimization.  
一个围绕 BOSS 直聘工作流设计的 agent-first CLI，覆盖职位搜索、筛选、招聘流程支持和简历优化。

I’m interested in workflow products where AI is not a feature bolted on top, but the operating model of the product itself.  
我对这类产品的兴趣在于：AI 不是附加功能，而是产品本身的运行方式。

### [wechat-writing-style](https://github.com/Fmaverick/wechat-writing-style)
A writing-style skill for Chinese public-account content creation.  
一个服务于中文公众号内容创作的写作风格技能包。

The deeper idea here is that taste, structure, and editorial judgment can be systematized without becoming generic.  
这个项目背后的核心判断是：审美、结构和编辑判断力，可以被系统化，而不必因此变得平庸。

### [tarot](https://github.com/Fmaverick/tarot)
An interactive TypeScript product experiment combining interface, story, and lightweight intelligence.  
一个结合界面、叙事与轻量智能的 TypeScript 交互产品实验。

I like software that feels emotionally legible, not just functionally correct.  
我偏爱那种不只“功能正确”，而且“情绪上可感知”的软件。

## How I Think / 我怎么思考产品

- The best tools reduce cognitive load, not just manual effort.  
  好工具减少的不只是体力操作，更是认知负担。
- Product taste is a real differentiator, especially in AI-native software.  
  在 AI 原生软件里，产品审美是真正的差异化能力。
- Small software can still have a strong point of view.  
  小软件一样可以有很强的产品观点。
- Shipping matters because learning compounds in public.  
  持续发布很重要，因为公开环境里的学习会复利。
